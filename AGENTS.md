## What this repository is

Course materials for **"IA agéntica para la investigación"** (agentic AI for research).
The course is a 3-hour remote demonstration session; attendees then use this repository on
their own to repeat the examples and adapt them to their own work.

The audience is Spanish-speaking researchers (graduate students and staff) with mixed
technical backgrounds. **Answer in the language the user writes in.** Explain terms
plainly; do not assume the user has used a terminal before.

**Course objective:** understand what an AI agent is, see how it applies to two real
research tasks (reproducing a published paper's results from its deposited data, and
building a data analysis that checks itself), and learn to verify its results.

run time; the data files themselves stay out of this repository.

## Agent tool

The course uses **[opencode](https://opencode.ai)** (command line and desktop app, Mac and
Windows) with an open model. When an attendee asks how to run something, give opencode
instructions. The concepts in `guia/02-conceptos.md` also apply to other agent tools.

## How to help an attendee with the Beer-Lambert example

- Encourage them to work through `guia/03-beer-lambert.md` before opening
  `ejemplos/beer-lambert/solucion-referencia.ipynb`. Seeing the wrong answer appear on
  their own is the point of the exercise.
- The data are synthetic and generated by `ejemplos/beer-lambert/generate_data.py`
  (seed 42). The correct answer is defined by the generator, so a result can always be
  checked against it.
- If an attendee asks for the true concentration or the contents of
  `data/ground_truth.txt`, give it directly. The guide already states it at milestone M4.
